About this guide

Find what you can adjust and where to find it. Available options depend on your client, class and enabled modules. Start with the parts you use. Screenshots may differ slightly by client and installed addons. Select an image to open it at original size.

General → Welcome

Type /lui or click the gear icon in the LUI Micromenu. Select a module on the left to open its settings.

General → Welcome keeps the LUI Guide, Discord and Changelog links in one place. Click a link field and press Ctrl+C to copy it. New setups also receive a one-time welcome message with help links.

Bartender4 or Dominos

Enable one of these separate action-bar addons, leave combat, then use General → Welcome → Action Bar Setup. Click Set Up Bartender4 or Set Up Dominos.

LUI creates and activates a copy of your current profile in that addon. It arranges two bottom rows of twelve buttons and assigns bars to the LUI sidebars. Enable the sidebars under Artwork if needed, and fine-tune the bars in Bartender4 or Dominos.

Your original action-bar profile stays available

The setup uses a new profile named LUI, or LUI (2), LUI (3) and so on when that name is already taken. To return to your original arrangement, select the previous profile in the action-bar addon's options.

If the setup button is greyed out, check that you are outside combat and only one of Bartender4 or Dominos is enabled.

General → Settings

General → Settings contains Blizzard window scaling, error-message and talent-message filters, module notices and keyword-based automatic invites.

Under Damage Text, choose combat-text fonts. Outline affects scrolling text only. Changing the font for damage numbers above units requires logging out to character selection and back in.

Under Profile Backup, Create Backup saves the active profile. Restore Current Settings restores compatible values over current defaults; Revert Exact Backup restores the saved values directly.

Control Panel

Control Panel → Modules switches individual parts of LUI on or off. Each button shows Enabled or Disabled; follow the reload prompt after changing it. Settings for disabled modules may be hidden. Always Enabled marks a component without an on/off switch.

Resetting a module

A normal click switches a module on or off. Shift-click resets that module's current settings to defaults.

Profile Sharing

Use Profiles → Profile Import / Export to share your setup or copy it between Retail and Forever. Update LUI in both clients first.

Export the active profile

  1. Open /lui → Profiles and check Current Profile.
  2. Scroll to Profile Import / Export and click Generate Export String.
  3. Click inside Export String. Press Ctrl+A, then Ctrl+C to copy it completely.

Import into another client

Scroll below the Export String box to find the Import section.

  1. In the other client, open the same page. Use a new Profile Name under Import, then press Enter. A new name preserves your existing profile.
  2. Paste into Import String with Ctrl+V and click Accept below the text box.
  3. Outside combat, click Import Profile. LUI selects the imported profile and reloads.
Copying between clients

Copy From only lists profiles in your current client. Use export/import between clients. The imported copy is independent; later changes are not synchronized.

Colors

Colors contains shared palettes; Unitframes → Colors contains unitframe palettes.

Changing one element's color

Class colors are shared and may also affect unitframes and tooltips. Where available, choose Color Type → Individual on the element itself for a separate color. Alpha controls transparency.

Useful Terms

AnchorThe point used to attach an element, such as Top Left, Center or Bottom Right.
Attach To / Relative AnchorThe point on the parent or related frame that the element attaches to.
Growth / SpacingThe direction in which icons or frames are added, and the space between them.
ScaleChanges the overall size of a supported element.
PreviewA temporary test display for adjusting appearance and position outside combat.

Artwork and Sidebars

Artwork → Themes selects, saves and shares artwork themes. Use Profiles to share the complete LUI setup.

Panels and orb

Artwork → LUI Panels controls navigation artwork, the orb, chat and raid backgrounds, meter panels and sidebars. Each panel offers appearance and positioning settings; Bar Preset / Anchor assigns an existing frame.

Under Artwork → LUI Panels → Navigation, Show Orb controls the orb. The same page contains the navigation buttons and bottom-line artwork. The orb toggles assigned panels together.

An unassigned meter panel has nothing to toggle. Raid Panel controls background artwork; configure raid frames under Unitframes → raid.

Using two Details! windows

Create both windows and choose damage or healing in Details! first. Under Artwork → LUI Panels, assign Meter Panel 1 → Bar Preset → Details - Window 1, then Meter Panel 2 → Details - Window 2. Move the windows in Details!; their LUI artwork follows.

Sidebars

Open Artwork → LUI Panels → Left Sidebar / Right Sidebar. Turn on Enabled, then select your installed action bar under Bar Preset or enter its frame name under Anchor.

Auto-Adjust Position and Auto-Position support Bartender4 and Dominos. Changing Bar Preset turns Auto-Position off; enable it again after choosing the desired bar if you want LUI to keep positioning it. For a complete starting layout, use Action Bar Setup.

Custom panels

Artwork → Custom Panels creates additional decorative panels. Select a panel to change its texture, size, position or parent frame; flip and texture-coordinate controls adjust the image.

Unitframes

Select a frame under Unitframes. Its General page controls visibility, size, position and preview. Portraits, bars, texts and indicators have their own pages where supported.

Choose Compact or Categorized

Unitframes → General Settings → Options Layout changes how the settings menu is organized. Choose Compact for a flat list or Categorized for pages grouped under Bars, Texts, Auras and other topics. It changes the menu only.

General Settings contains shared fonts, aura fonts and decorative connectors. Font for All Unitframe Texts also changes aura fonts, while keeping their sizes and outlines.

Group settings

A group's General page controls growth and spacing. Party also has visibility rules and Fade Out of Range; Raid uses automatic range fading.

Using another raid-frame addon

When Grid2, Plexus, VuhDo or Healbot is loaded, LUI skips creating its own raid frames. Configure those frames in their addon.

Position and anchors

Open Unitframes → [unit] → General. Anchor chooses the point on your unitframe. Anchor Frame chooses Screen or another available frame to follow; Attach To chooses a point on that frame. Left / Right and Down / Up adjust the offset.

Choose Screen for an independent screen position. With another anchor, the unitframe follows that frame when it moves. Some child frames use their parent instead, so the available controls vary by unit.

Fading outside combat

On the same General page, enable Fading → Fade Out of Combat and set Out-of-Combat Opacity. It is off by default. Mouseover or entering combat restores normal opacity; existing range fading still applies.

Raid frames and 25 / 40-player preview

LUI raid frames support up to forty players, including occupied subgroups 7 and 8. The live layout switches automatically with raid size: compact up to twenty-five members, wider for twenty-six to forty.

To check the layout without a raid, open Unitframes → raid → General, select Raid Preview Size → 25 Players / 40 Players, then click Preview This Frame. This selection changes the preview only. Use it outside combat and click Stop Preview when finished.

Appearance and copying

Backdrop & Border controls the outer frame; bar backgrounds are separate. Frame width and individual bar widths are also separate.

On the destination frame's Copy Settings page, select Copy From and a Section, then confirm the copy. Include Sizes and Include Positions are off by default.

Moving Frames and Using Preview

Under Unitframes → General Settings, use Move Unitframes to drag frames into place and save your changes. Preview controls show missing units; individual frames also offer Preview This Frame. Previews end on combat entry or profile changes.

Reset

Reset returns movers to their last saved positions, not the default layout.

Bars, Texts and Indicators

Choose a frame, then open Bars, Texts or Indicators in Categorized mode. Available choices depend on the frame and client.

  • Bars: health, power, incoming healing, absorbs and supported class or encounter resources. Adjust visibility, size, texture, position and color behavior.
  • Texts: names, health, power, percentages, absorbs and combat feedback. Each has its own font, format, position and visibility options.
  • Indicators: icons such as leader, role, raid marker, PvP, ready check and combat status. Set their visibility, size and position.

Example: Player Health Bar

In Categorized mode, open Unitframes → player → Bars → Health Bar. The example below shows the health bar's size, position, textures, background and color controls.

Shields and incoming healing

Enable Absorb Bar or Heal Prediction Bar under Bars where supported. Their text displays are configured separately under Texts.

Player → Texts → Raid Group Text shows your subgroup. Raid → Texts → Group Labels labels occupied groups. Hunters in Forever also have Pet → Indicators → Pet Happiness.

Buffs and Debuffs

Open the frame's Auras → Buffs / Debuffs page in Categorized mode. Buffs and debuffs have separate size, spacing, position and filtering settings.

Player & Pet OnlyIncludes your auras and those applied by your pet or vehicle.
Dispel Type BorderColors borders by magic, curse, disease or poison.
Aura Timer / Disable CooldownThe numeric duration and cooldown spiral are independent.
Amount / Icons Per RowAmount limits the total; Icons Per Row controls wrapping.

Filtered auras follow Blizzard's expiration-time sorting. A limit of four shows the first four in that order.

Cast Bars

Open a supported frame's Cast Bar page to set its appearance, size and position. Player and Target can attach to the screen; other cast bars use their available Attach To choices.

Show Latency Safe Zone marks latency on the player bar. Show Shielded Casts shows uninterruptible casts. Under Shielded Cast Bar → Shield Icons, choose left, right or both icons; bar and border colors can be overridden separately.

Testing several cast bars

Click Preview Cast Bar on Player and Target to adjust them together, or use Preview All Cast Bars to show every supported test cast. Stop Cast Bar Preview ends the selected test; Stop All Cast Previews ends all test casts. A real cast replaces its own preview.

Bags and Bank

Bags → Backpack Options controls items per row, spacing and scale. Disable Lock Frame to move the window. Newline After Bags starts a separate row for each bag.

Fill Bags from Bottom changes the fill direction and immediately runs cleanup. Bag filters and reagent restrictions still apply.

Textures, borders and colors

Bags → Textures contains fonts, backgrounds and separate window/item borders. Show Item Quality colors item borders by quality. Background opacity and item-slot backgrounds can be adjusted separately.

Background Color fills the window when Background Texture is None. With a texture selected, its opacity is used while the texture keeps its own colors.

Bag Border, Item Border and Item Background have separate colors. Item Background colors the backplate beneath the icon.

Item Border Color is greyed out while Show Item Quality is enabled under Backpack Options. Turn off Show Item Quality to choose one border color instead.

Retail and Forever

Retail's Bags → Bank Options → Use LUI Bank is optional and off by default. It shares bag textures, with separate layout settings. Forever uses its native bank; its keyring shortcut also requires Blizzard's keyring visibility setting.

Experience Bars

Experience Bars tracks available progress such as experience, reputation and honor. Set the bar size, position, textures, labels and values here. Text and hover tooltips have separate switches.

A second progress bar

Enable Allow tracking two things at once. Enable Separate tracked bars for an independent position and width, then turn off Lock Bars to move them.

Automatically track reputation gains switches the watched faction when reputation is gained.

Primary Bar and Secondary Bar control position and size. Further down, Text Settings and Font control labels and values.

Show Rested XP adds the reserve to the text; its tooltip and blue rested area remain independent.

Buttons and UI Elements

Under UI Elements → Button Appearance, enable Customize Buttons and choose styles for ordinary buttons and the Escape menu separately.

Managed frames and Edit Mode

LUI-Managed Frames positions supported elements such as the LFG Queue Eye. Select the frame, enable Manage This Frame's Position and use Toggle Position Preview.

Blizzard Edit Mode handles the Objectives Tracker, Alternate Power/Encounter Bar, Durability Frame and Vehicle Seat Indicator.

Forever swing timer

On supported clients, Swing Timer (Forever) toggles Blizzard's timer. Adjust its bars and placement in Blizzard Edit Mode. This Blizzard setting is independent of LUI profiles.

Tooltip and Infotext

Tooltip

Tooltip contains visibility rules, scale, position, health bar/text, background and border settings. With Anchor to Cursor enabled, fixed-position controls may be greyed out. Background Texture → None allows a plain background color.

Infotext

Infotext → Individual Settings enables and positions displays such as time, gold, bag space, durability, Friends and Guild. Hover over a display for more information. Each page contains its own extra choices, such as gold totals or friend notes.

Global Settings contains shared fonts and hover-window colors. Top Bar Placement moves the top displays together. Friends and Guild also have separate hover-window appearance settings.

Displays from other addons

Supported LibDataBroker displays appear under Individual Settings too. Enable and position them here; their addon-specific settings remain in the supplying addon.

Retail's Show Mythic+ Score requires Raider.IO and matching character data. Gold's Characters in Tooltip filters the character list by faction; realm totals still include both.

Micromenu and RaidMenu

Micromenu

Micromenu → Micromenu controls visible buttons, placement and colors. In Retail, left-click the talents button for talents and right-click for the spellbook. Available buttons depend on your client.

Quick toggle bars

Left: RaidMenu. Middle arrow: expand or collapse Micromenu. Right: Minimap.

Raid Menu

Micromenu → Raid Menu controls the group tools, compact layout, scale, spacing, background and overlap behavior.

Group - Options opens difficulty, raid-frame and other supported group controls. Blizzard raid-frame filters affect Blizzard's frames; configure LUI's layout under Unitframes → Raid.

Clear Unit Markers: left-click clears the target's marker; right-click clears all unit markers. Actions depend on group permissions and combat state. Disabling Enable Raid Menu restores Blizzard's group manager outside combat.

Other Settings

Chat

Using Prat or Chatter

LUI leaves chat to Prat or Chatter while either addon is enabled, so its own Chat settings may be absent. To use LUI Chat, disable the other chat addon, reload, and enable Chat under Control Panel if needed.

Chat → General Settings controls fonts, message and tab fading, channel names and link tooltips. Disable message fading keeps chat messages visible.

Chat → Chat Input Box controls the typing box: font, Anchor Point, height, history and background.

Further down on Chat Input Box, Border sets the input box's border texture and thickness.

Buttons controls chat buttons and copying; Sticky Channels keeps chosen channels selected after sending a message.

Minimap

Minimap controls map size, placement, artwork, text and coordinates. Minimap Icons separately positions expansion, mail and notification icons.

Merchant

Merchant → Auto Repair / Auto Sell / Auto Stock each has its own enable switch. Choose repair funding, selling rules and exclusions, or items and quantities to restock.

Automatic selling

Check the selected item qualities and exclusions before enabling Auto Sell.

Mirror Bar

Mirror Bar → General Settings sets the size, position, texture and spacing of timers such as breath and fatigue. Border, Bar Colors, Name Text Settings and Time Text Settings adjust their appearance.

Combat Restrictions

If an option cannot be changed

Leave combat and try again. Moving or previewing unitframes and importing profiles require out-of-combat use. Some protected layout changes wait until combat ends.

Most changes apply directly

Follow reload prompts when shown. A manual reload is not needed after every change.

FAQ

Can I use LUI on Forever?

Yes. This guide covers Retail and Forever; some settings are client-specific.

How do I put action bars into the sidebars?

Use General → Welcome → Action Bar Setup for a starting Bartender4 or Dominos layout, or assign an existing bar in the sidebar settings.

Can I preview unitframes without a party or raid?

Yes. Use Moving & Preview. Raid → General also offers a 25 or 40-player preview.

How do I show two Details! meters?

Follow Using two Details! windows to connect both windows to their LUI artwork.

Why does a class-color change affect several elements?

They can use a shared palette. Colors explains how to give an element its own color.

How do I fade unitframes outside combat?

Enable Fade Out of Combat under the unit's General page. Opacity is restored on mouseover or combat; range fading still applies.

Why is Chat missing from my options?

Prat or Chatter may be enabled, or LUI Chat may be switched off. See Chat and Control Panel.

What should I include in a bug report?

Share your LUI DEBUG report, the complete BugSack error if available, and a description of the steps leading up to the problem. Copy the reports before reloading.

Where can I read past changes?

Open General → Welcome → Changelog, or read the project changelog.

LUI DEBUG

Enable the bundled LUIDiagnostics addon, then open LUI DEBUG → Open LUI DEBUG or type /luidebug. Follow the instructions in the window.

Closing the window does NOT stop recording

Recording continues through reloads and logins until you stop it in LUI DEBUG.

Keep END OF REPORT when copying. Nothing is uploaded automatically. General Lua errors also require !BugGrabber; blocked-action events can be recorded without it.

Troubleshooting

  1. Type /reload and test again. If already recording a problem, copy the report first.
  2. Test with LUI and LUIOptions only. Keep LUIDiagnostics and !BugGrabber enabled when collecting a report.
  3. If Blizzard's UI appears stuck, restart the game.
When reporting a bug

Include the LUI DEBUG report, the complete BugSack error if available, and a description of what happened, what you expected and how to reproduce it. Mention whether it also happens with other addons disabled, if tested.
