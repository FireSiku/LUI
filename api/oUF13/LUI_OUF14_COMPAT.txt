LUI / oUF integration notes

Framework: complete official upstream snapshot, without LUI source changes.
Source: https://github.com/oUF-wow/oUF/tree/14.2.1
Upstream commit: c5ff6e4a09bfaf2186e205777e0fab964b5cddc1 (2026-10-31)
Packaged version: 14.2.1 (official release, published 2026-11-03).
Only the standard project-version packaging tokens are replaced with this version;
unchanged files retain their existing line endings.
The api/oUF13 directory name is retained for existing load paths.

LUI owns its compatibility code in modules/unitframes:
- layout/layout.lua: power colors, explicit Mana gradients, fractional class
  resources, backgrounds, health/absorb presentation, resource layout and
  the Retail 12.1.0 PvP indicator override. PvP icons retain LUI's configured
  dimensions through useAtlasSize on Forever and PostUpdate on Retail 12.1.5.
- layout/auras_12_1.lua: native AuraContainer presentation.
- castbar_compat.lua: temporary Blizzard castbar ownership and restoration.
- classpower_compat.lua: Forever target-bound combo points and their events.
- arena_compat.lua: native specialization display on preparation-only frames;
  real arena buttons keep their unit watches and active elements.
- groupheaders.lua: bounded Forever headers initialized outside combat.

Do not patch bundled framework files for LUI-specific behavior. Use oUF's
layout callbacks, color overrides and initialization hooks instead.

API review, 2026-10-24:
- Retail 12.1.5 build 70575; Forever 1.60.1 build 70532.
- oUF 14.2.0 remains the latest numbered release. This snapshot adds upstream
  secret-GUID scrubbing for group frames, native arena specialization display,
  arena tags and unitless master-looter event registration.
- The LUI arena integration replaces oUF's raw GetArenaOpponentSpec path on
  clients with native arena-display delegates. Secret specialization data is
  forwarded to text, color and alpha widgets without addon-side decisions.
  Preparation views hide when live units appear, the match engages, combat
  starts, the parent hides or arena frames are disabled.
- LUI keeps oUF-enableArenaPrep disabled on its real arena buttons. The new
  upstream preparation lifecycle and class-color CVar changes therefore do
  not run alongside LUI's preparation views, which follow the native CVar.
- The reviewed Retail and Forever changes require no further LUI adaptations.

API review, 2026-11-04:
- Retail 12.1.5 build 70783; Forever 1.60.1 build 70755.
- Official release 14.2.1 adds two source changes over the previous snapshot:
  leader tags use the supplied unit, and Stagger only restores or disables the
  stock MonkStaggerBar on Retail, where that Blizzard frame exists.
- All 47 official framework files match upstream, apart from standard version
  token replacement and preserved line endings. LUI's separate arena preparation
  views and oUF-enableArenaPrep = false are retained.
- UNIT_COMBAT now marks its amount as secret on both clients. The LUI-owned
  CombatFeedback plugin forwards it to FontString:SetFormattedText without a
  Lua comparison; ordinary zero amounts keep their absorb/block/resist behavior.
