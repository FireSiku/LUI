LUI oUF 14.0.3 / Blizzard 12.1 compatibility notes

Base: FireSiku LUI Retail.
Framework: official oUF 14.0.3 core and element load list.

The bundled framework is based on official oUF 14.0.3. FireSiku's existing
Retail renderer compatibility is retained at StatusBar call sites: ColorMixin
objects are unpacked to numeric RGB values because Blizzard 12.1's
SetStatusBarColor expects numeric components. oUF colors.lua remains unchanged.

Additional LUI compatibility includes Blizzard 12.1 AuraContainers,
DurationObject castbars and totems, secret-safe Health/Power display paths,
current healing and absorb widgets, combat-safe refreshes, and out-of-combat
layout previews.

Resource compatibility backports (oUF 14.1.1):
- GameVersion/GameCompatibility tables and ClassPower client gates.
- Cat Form, rather than Shred, determines druid combo-point availability.
LUI also fixes AdditionalPower gradients to evaluate Mana explicitly and
preserves fractional ClassPower values below 0.1. The embedded base remains
14.0.3; this is not a full framework upgrade to 14.1.1.
