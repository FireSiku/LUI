# LUI

LUI is a user interface replacement for World of Warcraft Retail. It combines the original LUI artwork with unit frames, infotexts, chat settings, bags, a minimap, a micro menu and other interface modules.

## Features

- Original LUI artwork, themes, panels and sidebars
- Unit frames for player, target, focus, pet, party, raid, boss, arena and main tanks
- Auras, cast bars, class resources, absorbs and heal prediction
- Infotext displays for Friends, Guild, Gold, Bags, Clock, Currency and more
- Chat, bags, minimap, micro menu, mirror bar, raid menu, tooltip and experience bars
- Profiles, import and export, and per-profile backups

Most modules can be enabled or disabled from the LUI options. Optional presets are available for common action-bar, damage-meter and raid-frame addons.

## Installation

Install LUI Core with the CurseForge app. Both `LUI` and `LUIOptions` are included.

## Settings and profiles

Open the settings from the LUI micro menu or with the LUI options command. Profile import and export includes module settings, the selected artwork theme and the unit-frame layout.

The profile page also provides Backup, Restore and Revert actions. The `/luibackup`, `/luirestore` and `/luirevert` commands use the same saved backup.

## Compatibility

LUI v2609 supports World of Warcraft Retail 12.1 and includes oUF 14.0.2. The Classic version is maintained separately.

## Reporting a problem

Please include the complete Lua error, the option or frame involved, the steps needed to reproduce it and a screenshot for visual problems.
